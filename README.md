# Savee - Video & Audio Downloader

Um aplicativo moderno feito em Flutter para baixar vídeos e áudios do YouTube e TikTok com facilidade, rapidez e com uma interface premium, salvando tudo diretamente na Galeria do seu dispositivo.

## 📥 Download Rápido (Pronto para Usar)

Se você não quer compilar o código e apenas quer instalar o aplicativo, baixe o arquivo APK já pronto na pasta `Releases_Para_Baixar` deste repositório:

1. 📱 [Baixar APK para Android (Savee_v1.3.apk)](Releases_Para_Baixar/Savee_v1.3.apk)

## 🚀 Funcionalidades Principais

- **Múltiplas Plataformas:** Suporte nativo para baixar conteúdos do YouTube e TikTok.
- **Anti-Bloqueio Avançado:** Mecanismo inteligente para contornar restrições de download de áudio.
- **Galeria Integrada:** Arquivos são salvos na pasta pública (`Mídia`) do Android, ficando imediatamente visíveis no seu player de música e galeria de vídeos.
- **Interface Premium:** Design moderno com modo escuro automático, animações fluidas e suporte a gestos.
- **Gerenciador Embutido:** Histórico completo de downloads, botão de play/pause, e exclusão definitiva de arquivos diretamente pelo App.

## 💻 Como Compilar (Desenvolvedores)

Caso queira modificar o código:
1. Certifique-se de ter o [Flutter](https://flutter.dev/) instalado na sua máquina.
2. Clone este repositório.
3. Execute `flutter pub get` na pasta raiz.
4. Conecte um emulador ou dispositivo físico e rode `flutter run`.
